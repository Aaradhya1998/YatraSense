# Daily Progress Log

Fill this in at the end of every work session — takes 2 minutes, saves you from re-explaining state to Codex (which has no memory across sessions) and keeps the remote team in sync without a meeting.

**How to use with Codex:** at the start of a new session, paste that day's "Completed" + "Next session should start with" section into Codex before giving it a new task. This re-establishes context instantly instead of Codex guessing at your codebase state.

**How to use with the team:** copy the same entry into your WhatsApp/group thread as the async daily update.
